# Next.js

This is Next.js 16, newer than most training data: APIs, conventions and file
structure may differ from what you remember. Before writing code that touches
Next — routing, metadata, config, MDX, caching — read its guide in
`node_modules/next/dist/docs/`, and heed deprecation notices.

`next dev` would write this reminder into an AGENTS.md of its own;
`agentRules: false` in `next.config.ts` turns that off, so this file is the
one place it lives.
